🔐 Privacy & backups

This version saves records in this browser on this device using local storage. It does not send your entries to a server or sync them to another device. Local storage is not encrypted, so anyone who can access this browser profile or device may be able to see the data. Use a device lock, avoid shared/public devices, and export a backup if needed. Clearing browser data can erase your records.

🔒 Important: browser-only storage is private from this website's server, but it is not the same as encrypted, account-based storage. For stronger protection across devices, this app would need a secure backend with authentication, encrypted transport, access controls, and a carefully designed backup system.
